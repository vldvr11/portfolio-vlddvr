p/card — product photo tool

A web tool for preparing product photo cards: compositing a product onto a background and shadow, color matching, and matching a reference look. Built for personal use and used at work at Terra Pro (THE ONE).

Direction
Web & Tools
Format
Interactive
Tools
Photoshop
Branches Web tools
01

Act IApproach

Modules: shadow calibration, automatic color matching (ΔE down from 7.2 to 0.8), a clone/heal/spot/erase/restore/mask brush set, background keying, and color grading via LUT/.cube files plus grain. Version 1.1 added IndexedDB autosave, automatic image-pair matching by filename, an 'edge' block, a background eyedropper, and rotate/flip. Version 1.2 added a Photoshop-style tabbed right panel (Product/Color/Scene/Export) with F1–F4 hotkeys.

02

Act IIResult

Per the author's own check (no QA agent run): the frame matches the reference within ±1–5 px, shadow RMS is 1.1–1.6 levels, and color ΔE is ≤ 0.5.
