Cutout — расширение для Chrome

Расширение Chrome для вырезки объектов с фото в один клик с помощью нейросети SAM 2.1, работающей локально в браузере.

Акт IПодход

Собран полный комплект для публикации в Chrome Web Store (описания RU/EN, локализация, privacy-policy), манифест v1.3.0 (попап, редактор, фоновый сервис-воркер, хоткей Alt+Shift+X), собственная дизайн-система «Cutout»: тёмная тема по умолчанию с сине-фиолетовым свечением, светлая тема, скругления 22–26px/14–16px/999px, градиент #4f8bff→#8b5cff, шрифт Onest. Функции: выделение одним кликом, уточнение Alt+клик/рамкой, кисть и ластик, доводка краёв нейросетью, работа с несколькими объектами, экспорт без потерь (меняется только альфа-канал).
